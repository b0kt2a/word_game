# 방핑 한글 자모 단어게임 뼈대

## 현재 들어간 기능

- 참가자 닉네임 입장
- 운영자 페이지 분리
- 운영자가 문제 시작 / 힌트 공개 / 정답 공개 / 다음 문제 조작
- 참가자 화면 자동 전환
- 한글 자모 자동 분해
- 위치 일치 / 위치 불일치 / 없음 판정
- 중복 자모 개수 판정
- 문제당 최대 5회 입력
- 정답 순서 실시간 카운팅
- 운영자 화면 실시간 정답자 목록
- 참가자 화면에 `몇 번째 정답자` 표시

## 로컬 실행

```bash
npm install
npm start
```

브라우저 주소:

- 참가자: `http://localhost:3000`
- 운영자: `http://localhost:3000/admin`

기본 운영자 키:

```text
bangping-admin
```

## 문제 수정

`data/questions.json`을 수정하면 됩니다.

```json
[
  {
    "answer": "자물쇠",
    "hint": "방탈출에서 자주 만나는 물건"
  }
]
```

수정 후 서버를 다시 시작해야 반영됩니다.

## Render 설정

- 서비스 종류: Web Service
- Build Command: `npm install`
- Start Command: `npm start`
- 환경변수:
  - Key: `ADMIN_KEY`
  - Value: 원하는 운영자 비밀번호

## 지금 버전의 주의점

현재 참가자, 진행 상태, 정답자 기록은 서버 메모리에 저장됩니다.

따라서 아래 상황에서는 기록이 초기화됩니다.

- Render 서버 재시작
- 새 배포
- 무료 인스턴스가 잠들었다가 새로 시작되는 경우

정모용 최종 버전에서는 DB 또는 외부 저장소를 붙이는 편이 안전합니다.
