WORD GAME 참가자 로그인 수정본

수정 파일:
- public/game.js
- public/index.html

변경 사항:
1. 자동 로그인 유효시간: 최초 닉네임 입장 후 6시간
2. 재접속/화면 꺼짐/네트워크 전환 시 6시간 이내면 기존 참가자로 자동 복구
3. 재접속할 때마다 6시간이 연장되지 않음
4. 6시간이 지나면 localStorage의 참가자 ID/닉네임/로그인 시각을 삭제하고 닉네임 입력 화면부터 시작
5. 참가자 화면 하단에 '다른 닉네임으로 입장' 버튼 추가
6. 다른 닉네임 버튼은 기존 서버 기록을 삭제하지 않고, 현재 브라우저 로그인 정보만 초기화
7. 닉네임 변경 시 소켓을 끊었다 재연결해서 기존 온라인 접속도 정상 정리

적용:
GitHub 저장소의 public/game.js 와 public/index.html 을 이 파일들로 교체 후 push.
server.js 수정은 필요 없음.
